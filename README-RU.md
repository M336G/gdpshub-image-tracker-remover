# GDPS Hub Image Tracker Remover
Не палите свой IP при просмотре приватки на GDPS Hub, проксируя все возможные изображения в описании сервера

Это расширение исправляет до сих пор не исправленный GDPS Hub'ом эксплоит, позволяющий любому, кто добавит картинку в описание их приватки, видеть IP-адреса тех, кто смотрит их приватку, проксируя все запросы на изображения не с GDPS Hub'а.
