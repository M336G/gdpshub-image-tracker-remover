# GDPS Hub Image Tracker Remover
Avoid leaking your IP when checking a GDPS page by proxying all images potentially displayed on it

This extension fixes a client-side vulnerability that has still not been resolved by GDPS Hub, allowing anyone adding an image to their GDPS description to track IPs of people clicking on their GDPS page by proxying requests made to hosts that aren't officially used by GDPS Hub for images.
