# GDPS Hub Image Tracker Remover
Évite de leaker son IP lors de la visite de la page d'un GDPS en proxiant toutes les images qui y sont potentiellement affichées

Cette extension résout une faille de sécurité côté client qui n'a toujours pas été corrigée par GDPS Hub, permettant à quiconque ajoutant une image à la description de son GDPS de traquer l'adresse IP des personnes cliquant sur la page de leur GDPS, en faisant passer par un proxy toutes les requêtes faites à des hôtes qui ne sont pas officiellement utilisés par GDPS Hub pour des images.
